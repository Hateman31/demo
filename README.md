# Валютный конвертер и Кредитный калькулятор

Десктопное приложение на Python для конвертации валют и расчёта кредитов с графическим интерфейсом.

## 📌 О проекте

Приложение предоставляет два основных функционала:
1. **Конвертер валют**: Позволяет конвертировать рубли (RUB) в другие валюты, используя актуальные курсы, получаемые из API Центрального Банка РФ.
2. **Кредитный калькулятор**: Рассчитывает ежемесячный платёж, общую сумму платежей и начисленные проценты по кредиту.

Также реализован встроенный **логгер** для отображения истории действий и сообщений об ошибках в интерфейсе.

## 🛠 Технологии

*   **Язык**: Python 3
*   **GUI**: `tkinter` (стандартная библиотека)
*   **Сеть**: `requests` (для работы с API)
*   **База данных**: `sqlite3` (хранение курсов валют в файле `currency_rates.db`)
*   **API**: [CBR XML Daily JSON](https://www.cbr-xml-daily.ru/daily_json.js)
